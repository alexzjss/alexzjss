## Research

### Benchmark Selection for Software Testing & Debugging

Undergraduate research through **PUB/USP**, with the **SAEG — Software Analysis and Experimentation Group**, advised by **Prof. Dr. Marcos Lordello Chaim**.

The research investigates Java software benchmarks for **Spectrum-Based Fault Localization and Automated Program Repair**, using **Jaguar 2** to collect execution spectra from real-world defective programs.

The work involves benchmark selection, experimental infrastructure, execution coverage, fault localization metrics and reproducible evaluation.

### TrendSurfer — Itaú Quant AI Challenge

Three-person quantitative research project focused on a **long/short momentum strategy** over the historical IBOV universe.

The project combines financial data ingestion, point-in-time universe construction, feature engineering, signal generation, historical backtesting and validation, with an emphasis on avoiding look-ahead and survivorship bias.
